後台登入

輸入 GitHub 帳號與存取權杖（Token）以編輯網站文字內容。這組資料不會上傳到任何地方，只會用來直接呼叫 GitHub 幫你存檔。

忘記密碼／要換一組 Token？點這裡重新設定

沒有 Token？點這裡看怎麼申請（只需要做一次）
  1. 用電腦或手機瀏覽器開啟：https://github.com/settings/personal-access-tokens/new（需先登入 GitHub）
  2. Token name 隨意填，例如「網站後台」
  3. Expiration（有效期限）選你想要的天數，之後過期只要重新申請一次即可
  4. Repository access 選 Only select repositories，然後選這個網站所在的 repository
  5. 往下找到 Permissions → Repository permissions → Contents，改成 Read and write
  6. 捲到最下面按 Generate token
  7. 畫面上出現的一長串文字（github_pat_...）就是你的 Token，只會顯示這一次，請直接複製貼到上面「Personal Access Token」欄位
  8. 上面「Repository」欄位請填 你的GitHub帳號/repo名稱，例如 abc123/starpath-site

這個 Token 只授權「讀寫這一個 repository 的內容」，之後可以隨時到 GitHub 的 Token 設定頁面刪除或重新產生，不會影響你的 GitHub 帳號安全。

YouTube 頻道清單（自動抓取影片用）

網站會每 6 小時自動連到下面每個頻道抓最新影片／直播，顯示在「影片精選」頁與首頁。 頻道 ID 是 UC 開頭的一串英數字，可以到該頻道「簡介」頁面，或用網址列的 youtube.com/channel/UC....... 找到；如果頻道網址是自訂網址（例如 youtube.com/@名稱）， 可用「檢視網頁原始碼」搜尋 channel_id，或用網路上的「YouTube channel ID finder」工具查詢。

提醒：自動抓取需要在 GitHub repository 的 Settings → Secrets and variables → Actions 設定一組 YOUTUBE_API_KEY（YouTube Data API v3 金鑰），這一步無法從後台完成，只需要設定一次。
